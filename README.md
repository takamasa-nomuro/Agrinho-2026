# Projeto Agrinho 2026: Agro Forte, Futuro Sustentável
Este projeto foi desenvolvido com o intuito de participar do Concurso Agrinho 2026, que explora o tema "Agro Forte, Futuro Sustentável: Equilíbrio entre Produção e Meio Ambiente".

O objetivo é destacar como a produção agrícola e a preservação ambiental podem caminhar juntas, mostrando que é possível ter um agro forte sem comprometer os recursos naturais. A proposta é evidenciar a importância de práticas sustentáveis que promovam o desenvolvimento econômico e a conservação do meio ambiente, garantindo um futuro equilibrado para todos.

# Funcionalidades
Home - Ao abrir o site, você verá a barra de navegação com três ícones principais: o primeiro que direcionará o visitante a página inicial (home); o segundo levará para uma calculadora interativa, na qual se pode calcular a quantidade de carbono emitida, com base na distância percorrida de carro e no consumo de energia, além da quantidade necessária de árvores para compensar a emissão. Na página há também um ícone que redireciona o leitor à página inicial. Por fim, o terceiro ícone que, ao ser clicado, abre o site do Agrinho.
Além disso, a página inicial conta com a funcionalidade "muda cor", onde o leitor pode mudar a cor de fundo para melhor visualização e experiência de leitura. Também há um vídeo informativo sobre agronegócio, que é possível deixar em tela cheia e ter seu volume ajustado pelo usuário. Por último, a tela inicial conta com alguns cards que contém textos informativos, para melhor experiência ao navegar pelo site. os flip-card, Basta deslizar o mouse por cima, que as informações aparecerão ao usuário. 
No rodapé (footer), há um link para que o usuário possa retornar direto para a página inicial.
