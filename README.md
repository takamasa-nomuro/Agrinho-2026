# Projeto Agrinho 2026: Agro Forte, Futuro Sustentável
Este projeto foi desenvolvido com o intuito de participar do Concurso Agrinho 2026, que explora o tema "Agro Forte, Futuro Sustentável: Equilíbrio entre Produção e Meio Ambiente".

O objetivo é destacar como a produção agrícola e a preservação ambiental podem caminhar juntas, mostrando que é possível ter um agro forte sem comprometer os recursos naturais. A proposta é evidenciar a importância de práticas sustentáveis que promovam o desenvolvimento econômico e a conservação do meio ambiente, garantindo um futuro equilibrado para todos.

# Funcionalidades
Home – Ao abrir o site, você verá a barra de navegação com 3 ícones principais: o primeiro é o logo, que ao ser clicado retorna para a página principal; o segundo é Juntos Pelo Agro, que levará diretamente para esta página; o terceiro é Sustentabilidade, direcionando para a página correspondente; o quarto é Home, com função igual ao logo; e o quinto é Informações, que leva para a página principal e depois às informações de contato. Cada página possui áudios dos textos, permitindo aumentar ou diminuir o volume conforme necessário. No quadrado verde "Participe do Movimento" há um botão que direciona para a página Juntos Pelo Agro. O rodapé (footer) contém links rápidos para todas as páginas, facilitando a navegação.
Sustentabilidade – Mantém a mesma barra de navegação com 5 itens, áudios para cada texto com controle de volume. Ao final da página, há um card com efeito flip, que ao passar o mouse ou tocar na tela do celular, revela informações adicionais. O footer possui links rápidos iguais aos da página Home.
Juntos Pelo Agro – Navegação semelhante às demais páginas, com áudios para os textos e controle de volume. No final, há 3 links que direcionam para sites de projetos e ações sustentáveis relacionados à agricultura. O footer mantém os links rápidos das páginas principais.
